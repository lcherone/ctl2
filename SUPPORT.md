# Support

Use [GitHub Discussions](https://github.com/lcherone/ctl2/discussions) for adoption questions and design discussion when available. Use [GitHub Issues](https://github.com/lcherone/ctl2/issues) for reproducible defects and focused feature requests.

Include the package version, Node or browser runtime, module format, a minimal sanitized task or payload, expected behaviour, and actual behaviour.

For suspected vulnerabilities, follow [SECURITY.md](SECURITY.md) and use private vulnerability reporting.
